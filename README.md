# R2-CPU2
Quiz temático de Star Wars!
Nesse quiz o R2-D2 foi danificado e você precisa acertar perguntas para obter as peças para reparar o droid, a cada pergunta acertada você consegue uma peça e ao final se conseguir atingir 60% do quiz ou seja 6 peças, você consegue reparar o droid mais querido da galáxia, Você consegue?
